# F1 Engine Supplier Dominance — Hybrid Era Statistical Analysis (2015–2024)

## Overview
A quantitative study comparing four Formula 1 engine suppliers — Mercedes, Ferrari, Renault, and Honda — across 10 seasons of the hybrid era using descriptive statistics.

## Objective
To identify the most dominant engine supplier in F1's hybrid era based on four performance variables.

## Variables Analysed
- Championship Points (discrete)
- Podium Finishes (discrete)
- Top Speed (continuous, km/h)
- Engine Failures (discrete)

## Statistical Methods Used
- Arithmetic Mean, Median
- Q1, Q2, Q3 Quartiles
- Interquartile Range (IQR) & Quartile Deviation
- Variance, Standard Deviation
- Coefficient of Variation (CV)

## Key Findings
- Mercedes: dominant supplier — highest avg points (942.15), podiums (29.1), speed (361.66 km/h), lowest avg failures (3/season)
- Honda: most improved — failures dropped from 12/season (2015) to 1 (2024)
- Ferrari: highest reliability issues in 2018 and 2023 despite strong performance
- Renault: highest average engine failure rate across the decade
